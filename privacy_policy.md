## 4. Data Storage and Security

### 4.1 Data Storage

**Location:**
- Data is stored on secure cloud servers (Neon PostgreSQL)
- Servers are located in Sydney, Australia
- Data is backed up regularly

**Retention:**
- Account data: Retained while your account is active
- Code submissions: Retained for analysis history
- Session data: Retained for 7 days
- Logs: Retained for 90 days

### 4.2 Security Measures

**Technical Safeguards:**
- Encryption in transit (TLS/SSL)

- JWT-based authentication
- Rate limiting and DDoS protection

**Access Controls:**
- Role-based access control
- Multi-factor authentication (where applicable)
- Regular security audits
- Employee access restrictions

**Monitoring:**
- Continuous security monitoring
- Intrusion detection systems
- Regular vulnerability assessments
- Incident response procedures

While we implement industry-standard security measures, no method of transmission or storage is 100% secure. We cannot guarantee absolute security of your data.
